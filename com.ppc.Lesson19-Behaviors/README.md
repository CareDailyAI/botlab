# Lesson 19 : Behaviors

It's possible to define new Behaviors for a type of device that show up in the user's app.

## What you’ll build

- A location microservice (`intelligence/lesson19/location_behaviors_microservice.py`) that uses `signals.behaviors.set_behaviors(...)` to publish a menu for a device type and publishes a summary to `lesson19/behaviors`.

## Run locally (recommended)

```bash
botlab-tests --bundle com.ppc.Lesson19-Behaviors --directory tests
```
